Contributing
============

Any code contributions are welcome and it is the developer team's hope that this
guide facilitates an understanding of the ``ansys-tools-installer`` code
repository. It is important to note that while the ``ansys-tools-installer`` software
package is maintained by ANSYS and submissions are reviewed
thoroughly before merging, community members can help answer questions
and develop features that make this software useful to all users.
Questions and submissions to this repository are welcome.

For contributing to this project, please refer to the
`PyAnsys Developer's Guide`_.
